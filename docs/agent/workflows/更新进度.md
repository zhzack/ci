# 更新项目进度

请更新当前项目的持久化进度。

## 第一步：读取项目资料

阅读：

- docs/agent/项目说明.md
- docs/agent/当前进度.md
- docs/agent/架构说明.md
- docs/agent/决策记录.md

## 第二步：检查实际项目状态

检查：

- Git 状态
- 最近修改
- 当前代码
- 测试
- 配置
- 与本次任务相关的模块

不要仅根据聊天记录判断项目状态。

## 第三步：整理本次工作

明确区分：

### 已完成

实际完成并验证的内容。

### 进行中

已经开始但没有完全完成的内容。

### 未开始

目前尚未实现的内容。

### 已知问题

当前发现但没有解决的问题。

### 阻塞问题

导致后续工作无法继续的问题。

## 第四步：更新当前进度

更新：

`docs/agent/当前进度.md`

不要删除原有仍然有效的信息。

## 第五步：检查架构

如果本次工作改变了：

- 模块结构
- 数据流
- API
- 数据库结构
- 核心设计
- 组件职责

则更新：

`docs/agent/架构说明.md`

## 第六步：检查技术决策

如果本次工作做出了重要技术决策：

更新：

`docs/agent/决策记录.md`

记录：

- 决策
- 原因
- 替代方案
- 影响

## 最后

给出简短总结：

- 当前阶段
- 本次完成内容
- 当前问题
- 下一步建议

## 5. 当前已知问题与技术债务

1. **Windows 文件系统无法保留 POSIX 执行位**：
   - 现状：Windows 上运行 `chmod +x` 无效，测试用例 `tests/unit/test_folder_upload.py` 对 mode/exec bit 的断言在 Windows 下会自动 skipif 跳过。
   - 解决方案：已符合项目测试规范，长期通过容器化运行时彻底规避。
2. **SQLite 单文件写锁并发限制**：
   - 现状：开发环境 SQLite 在高并发心跳或任务密集提交时存在锁争用风险。
   - 解决方案：生产环境强制使用 PostgreSQL 14+（通过 Docker Compose 部署）。
3. **远程任务包在 API 服务内存驻留生命周期**：
   - 现状：远程任务 bundle 数据暂存于服务端内存 `engine.remote_inputs`，若 API 服务在任务领取的瞬间重启，会导致拉包 404（由启动孤儿收割机制判定为 FAILED）。
   - 解决方案：Phase 2 接入 S3/MinIO 对象存储后将由对象持久化接管。
